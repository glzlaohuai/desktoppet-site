# DesktopPet website design

Scene: a Mac user in a sunlit room takes a short break from work to meet a companion. The site should feel like a small, friendly toy box on their desk. Use a light appearance with a committed apricot hero, warm paper, espresso text, and a sage contrast section.

Voice: sunlit, tactile, unhurried. Reference lane: the original small pixel companions and a warm illustrated software package, with an asymmetric opening and crisp toy-like controls. No fake application windows, repeated feature cards, decorative dashboards or subscription framing.

Typography: Bricolage Grotesque, selected from the Google Fonts catalog for its open, friendly counters and distinctive compact display shapes. Self-host the variable font. Use system CJK fallbacks. Large fluid headings contrast with comfortable body text, capped near 70 characters. Pixel sprites always use nearest-neighbor rendering.

Original artwork and real localized app screenshots replace generated images. The character picker is an explicitly labeled website preview. Interactions are optional, respond to keyboard input, and announce changes. Disable all decorative sprite animation when Reduce Motion is requested. Six languages use real static routes so support and privacy remain available without JavaScript.
